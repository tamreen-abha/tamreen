# تمريني

تطبيق آيفون لخطة الـ12 أسبوعًا بوزن الجسم: جلسة بعد الفجر وجلسة قبل النوم، مع فيديو لكل تمرين، ووضع تمرين بمؤقت، وسجل تقدّم، وتنبيهات يومية تتبع وقت الشروق بتقويم أم القرى.

## البناء
عند رفع الملفات إلى GitHub يُبنى التطبيق تلقائيًا من تبويب **Actions**، ويخرج ملف `Tamreen.ipa` داخل حزمة `Tamreen-ipa`.

## التثبيت
ثبّت ملف `Tamreen.ipa` على الآيفون ببرنامج Sideloadly من ويندوز وحساب Apple ID. بالحساب المجاني يعمل التطبيق 7 أيام، ثم يُعاد تثبيته والبيانات محفوظة.
